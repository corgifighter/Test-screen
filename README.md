# Hearthmere — Nightfall Reborn

A self-contained mobile-first browser RPG prototype. No npm, no CDN, no external assets, no build step. Open `index.html` directly or serve the folder from any static host.

## Controls
- Tap the ground to walk.
- Tap a character/object to inspect or interact.
- Drag with a mouse to pan while testing on desktop.
- +/- changes zoom.
- Bottom action bar provides contextual actions.

## Visual direction
OSRS-inspired readability and low-poly fantasy forms, pushed toward richer modern lighting, atmosphere, architecture, material shading, water, foliage, environmental detail, and a polished mobile RPG interface.
